      这是Hextra Patterns文档的在线版本。

                                                                                                                                                                                                  保留式比较

                                                                                                                                                                                                  总有些时候，我会想要在对两个 iota 进行逻辑操作之后，还继续对它们执行其他操作。但这就需要每次都先复制，确实有些麻烦。而且复制也会给自然带去负担，复制大型 iota 时尤为如此，比如说列表等大到栈上限成为问题的那些。
